心之結晶 - 展場互動裝置專案目錄架構
==================================================


tearsPearls/
├── 📂 public/                   # 靜態資源 (不經 Vite 編譯，直接路徑存取)
│   ├── 📂 gems/                # 5種情緒結晶寶石素材 (各對應 .json 與 .png)
│   └── 📂 textImg/             # 20個情緒詞彙水波紋素材 (各對應 .json 與 .png)
│
├── 📂 src/                      # 核心邏輯
│   ├── 📂 assets/                    # 多媒體資源 (由 Vite 編譯)
│   │   ├── 📄 wait_720.mp4          # 待機播放影片
│   │   ├── 📄 wait_1080p.mp4        # 待機播放影片
│   │   └── 📄 wait_monitor.jpg      # 大螢幕待機圖片
│   │
│   ├── 📂 config/              # 全域參數設定
│   │   └── 📄 constants.js          # 詞庫、結算語錄、寶石情緒對應字典、物理參數
│   │
│   ├── 📂 engine/              # PIXI.js 互動渲染核心
│   │   ├── 📄 MonitorEngine.js      # 大螢幕：MediaPipe 臉部偵測、文字掉落物理運動
│   │   ├── 📄 TabletEngine.js       # 平板：全螢幕 Canvas 綁定、跨裝置座標接收
│   │   ├── 📄 MonitorController.js  # 大螢幕：WebRTC 鏡頭視訊 Cover 縮放控制器
│   │   └── 📄 TabletController.js   # 平板：水波特效、水花粒子、寶石顯影狀態機
│   │
│   ├── 📂 views/               # React UI 介面層
│   │   ├── 📄 MonitorView.jsx       # 大螢幕畫面：初始化 AI、待機圖層切換
│   │   └── 📄 TabletView.jsx        # 平板畫面：互動選詞 UI、閒置倒數、Socket 事件觸發
│   │
│   ├── 📄 main.jsx             # 應用程式掛載點
│   ├── 📄 App.jsx              # 路由分發器 (/monitor, /tablet)
│   └── 📄 index.css            # Tailwind CSS 全域樣式
│
├── 📄 server.js                # Socket.io 通訊中樞 (負責雙螢幕事件中轉)
├── 📄 index.html               # 網頁主入口 (防縮放設定、PIXI CDN 載入)
├── 📄 vite.config.js           # 建置與開發伺服器設定
├── 📄 package.json             # 依賴套件管理 (Pixi, GSAP, Socket.io, Tailwind)
├── 📄 .gitignore               # Git 忽略清單
├── 📄 DIRECTORY.txt            # 本專案目錄結構說明文件
├── 📄 To do.docx               # 專案待辦事項與進度追蹤
└── 📄 README.md                # 佈展執行手冊與操作說明
